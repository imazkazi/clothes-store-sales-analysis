# 🛍️ Clothes Store Sales Analysis Dashboard

This repository contains a comprehensive data analysis of a clothing store's annual performance using Excel dashboards. The insights include breakdowns by gender, age groups, channels, states, order status, and monthly trends.

---

## 📊 Dashboard Overview

![Screenshot_of_ANALYSIS](https://github.com/user-attachments/assets/82908e8d-ca90-442d-bcdc-3c2e6ffa1732)


### Key Insights:
- **Gender-wise Sales**: Women contribute to a significantly higher portion of sales.
- **Age Group Trends**: Adult women are the most prominent customer segment.
- **Monthly Trends**: Peak orders occur in February and March; revenue is highest in March.
- **Channel Distribution**: Flipkart, Amazon, and Myntra are the top-performing platforms.
- **Top States**: Maharashtra, Karnataka, and Uttar Pradesh lead in sales.
